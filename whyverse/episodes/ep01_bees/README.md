# Whyverse ep01 — "What If Every Bee Disappeared?" — editable project

This is the full source behind `ep01_bees.mp4` (v3, 9:00, 1920×1080, 30 fps): the timeline, every scene,
the soundtrack code, the narration audio, fonts, the thumbnail scene, the Shorts builder, and the
animation-studio skill it was built with. All artwork is drawn in code (canvas), and all music and sound
effects are synthesised in JavaScript, so there are no image or audio assets apart from the voice.

## What's in the box
```
ep01_bees/
  lines.json         the script: one entry per voice line [chapter, id, text]
  vo/                the narration: one Kokoro wav per line (voice af_heart, en-us)
  SCRIPT.md          script with timecodes · STORYBOARD.md shot list · NOTES.md sources + build notes
  RESEARCH.md        fact sources · PUBLISH.md YouTube/Shorts metadata · ep01_bees.srt subtitles
  thumbnail.jpg      1280×720 thumbnail
  tools/
    voice.py           regenerate voice lines with Kokoro (only needed if you change the script)
    build_timeline.py  measured wavs → film/timeline.js (line + word times, mouth track) + film/out/vo.wav
    make_srt.py        timeline → .srt
    make_shorts.py     final mp4 → five 9:16 Shorts with burned-in captions
    thumb.js           the thumbnail scene (see "Thumbnail" below)
    tile.sh            contact-sheet helper
  film/                the animation-studio project
    index.html         loads engine + timeline + events + score + scene files in order
    timeline.js        GENERATED by build_timeline.py (voice timing)
    events.js          every named visual hit and its sound effect, per chapter (edit timing here)
    score.js           single source of truth: reads timeline.js + events.js, exports SCORE for film and song
    lib.js             paper props: notes, stamps, counters, chapter cards + hook cards, food icons, trees, hives,
                       trucks, globe, Whyverse planet, bars, sparkles
    bee.js             the bee guide character (Ch.bee), lip-synced to the voice
    ch0.js … ch8.js    one file per chapter (cold open, 7 chapters, payoff + call-to-action end card)
    film.js            assembles all shots (Shots.film) + global post-processing
    song.js            music bed per chapter, stings, SFX on every event, voice mix and mastering (−14 LUFS)
    engine/            the vendored animation-studio engine (renderer, drawing, characters, maps, audio, fonts)
animation-studio/      the full skill folder (SKILL.md, references/, engine/, examples/, template/, scripts/)
```

## Requirements
- Node 22+, ffmpeg, and Google Chrome or Chromium (headless). No `npm install` needed.
- Python 3 with `numpy` and `soundfile` (for build_timeline.py). Optional: `kokoro-onnx` (voice.py) and
  Pillow (make_shorts.py).
- If Chrome isn't found automatically, set `CHROME_PATH=/path/to/chrome`. On Linux running as root, use a
  wrapper that adds `--no-sandbox`.

## Render the episode
Run these from inside `ep01_bees/`:
```bash
python3 tools/build_timeline.py            # → film/timeline.js and film/out/vo.wav (the voice placed on the timeline)
cd film
node song.js                               # → out/music.wav (voice + music + SFX, mastered), ~2–3 min
node engine/render.js sheet 0 540 48 6     # quick contact sheet → out/sheet.png
node engine/render.js stills 44 200 530    # single frames → out/stills/
node engine/render.js preview              # live preview with sound in the browser (prints a localhost link)
node engine/render.js video                # all 16,214 frames → out/video.mp4 (~70–80 min on 2 CPUs)
ffmpeg -i out/video.mp4 -i out/music.wav -map 0:v -map 1:a -c:v libx264 -preset medium -crf 29 \
  -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 160k -shortest out/ep01_bees.mp4
node engine/render.js verify               # sound/picture sync check at the markers (optional)
```
`node engine/render.js mux` also works (CRF 18, a much bigger file). Render times scale with the number of CPUs.

## How to change things
- **Timing of a hit (picture and sound together):** edit `events.js`. Hits are tied to spoken words with
  `Wt(lineId, 'word')`, so they follow the voice automatically.
- **Look of a shot:** edit that chapter's `chN.js`. Each `P.shot(time, draw, {in: transition, cam})` is one
  shot, and draw functions are pure functions of `t`.
- **The script:** edit `lines.json`, delete the changed line's wav from `vo/`, run
  `KOKORO_DIR=<folder with kokoro-v1.0.int8.onnx + voices-v1.0.bin> python3 tools/voice.py lines.json vo`, then
  `python3 tools/build_timeline.py`. Models: https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0
  If you use a different voice, keep one wav per line id; everything else re-times itself.
- **Mix levels:** `MUSIC_DB` (−23), `FX_DB` (−20) and `STING_DB` (−14) are environment variables of song.js,
  measured relative to the voice.
- **Style:** `STYLE` in score.js (`paper` here; the engine also has flat, chalk, neon, watercolor), or
  `--style neon` on any render command. Colours are in `lib.js` (`P.C`).

## Thumbnail
Copy `film/` to a scratch folder, replace the `ch*.js` and `film.js` script tags in index.html with
`thumb.js`, put tools/thumb.js next to it, and run `node engine/render.js stills 1`. Then scale the result to
1280×720.

## Shorts
`python3 tools/make_shorts.py film/out/ep01_bees.mp4 film/timeline.js <out_dir>` builds five 9:16 cuts with a
hook title, burned-in captions and a "Full video on YouTube" line. The segments and titles are listed at the top
of the script.
